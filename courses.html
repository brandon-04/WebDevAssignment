W3 Schools has excellent resources on every aspect of web development, from learning HTML and CSS to more complicated backend processes, such as PHP and SQL.

Geeks for Geeks explores most other programming concepts, such as variables, arrays, or even loops, which are must-knows if you plan to learn or use Javascript.

The Odin Project is a great set of structured courses covering every aspect of web design. It is well suited to those who like a slower-pace, more in depth learning experience.
